# KubeSmith Design System

Embodying the **29 Master Design Patterns**:
- **Bento Grid (#12)**: Asymmetric layout organizing PSS Security Gauges, Routing Topology, and Manifest Diagnostics.
- **Dark Mode UI (#20)**: Deep obsidian canvas `#070a12` with neon emerald, cyan, and rose status tokens.
- **Cybercore (#24)**: High-density Kubernetes cluster telemetry and tactical node routing HUDs.
- **Swiss Design (#3)**: Clean mathematical grid discipline and asymmetric typographic hierarchy.
